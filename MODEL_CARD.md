# Model Card — DistilBERT Learning-Paradigm Classifier (P2)

**Model:** `distilbert-base-uncased` (66M params, Apache-2.0), fully fine-tuned with **Keras 3 (PyTorch backend)** via `TorchModuleWrapper`, plus Dropout(0.1) + Dense(3, softmax).
**Task:** classify a free-text ML problem scenario as `supervised`, `unsupervised` or `reinforcement`.

## Intended use
Teaching aid for Generative-AI / ML courses. Not for production ML system design decisions.

## Training data
- 200 synthetic scenarios generated by `gpt-4.1-mini` (25 per domain × 8 domains: healthcare, finance, retail, robotics, gaming, manufacturing, agriculture, cybersecurity).
- 80/20 stratified split, seed 42. Max length 64 tokens. Adam, lr 5e-5, batch 16, 4 epochs (configurable in app).

## Evaluation (example run, CPU)
| Method | 20 hand-labelled accuracy | Mean latency |
|---|---|---|
| Zero-shot LLM (gpt-4.1-mini) | 100% | ~480 ms |
| Few-shot LLM (6 examples) | 100% | ~450 ms |
| Chain-of-thought LLM | 100% | ~1.9 s |
| DistilBERT (Keras fine-tune) | 75% | ~220 ms |

Tricky 10 (multi-stage, human-rating feedback, misleading cue words): zero-shot 80%, few-shot 70%, CoT 80%, DistilBERT 60%.

Held-out synthetic validation accuracy for DistilBERT: 92.5%. The drop from 92.5% (synthetic) to 75% (hand-written) shows the synthetic-to-real gap. Re-run on the app's Evaluation page for current numbers.

## Failure case
DistilBERT labels "A supermarket wants to know which products tend to be bought together from millions of receipts" (association rules → unsupervised) as **supervised**, and the banner A/B "which design earns most clicks" bandit problem as supervised. It leans on cue words (e.g. "flag", "predict") instead of whether labels exist.

## Bias & hallucination
- Per-domain accuracy is reported in the app (Evaluation + Responsible AI pages). With 2–3 gold items per domain, gaps are noisy.
- Hallucination test: the CoT algorithm suggestion is checked against a curated list of real algorithms for the predicted paradigm (grounding rate shown in app).

## Limitations
LLM-generated training data (single generator, cue-word leakage, forced balance, generator labels its own data), English only, hybrid paradigms (semi/self-supervised, imitation learning) not modelled.

## Safety
Input guardrail: length limits, prompt-injection patterns, harmful-content patterns, PII redaction (email/phone/card); LLM can answer `D = not an ML problem`.
